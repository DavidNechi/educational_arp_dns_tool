# Ethics and Legal Use

This project is for education in a controlled, authorized lab environment only.

- Use the tool only on networks you own or where you have explicit written permission.
- Do not run ARP/DNS manipulation on public or shared networks.
- Keep the lab isolated (host-only or private NAT) to avoid impacting others.
- If you are unsure about permission, stop and ask.

Security research requires consent, transparency, and safe boundaries. This lab is intended to help understand protocol weaknesses so you can learn how to defend against them.
